## 二、5大范式深度解析

### 2.1 ReAct：思考-行动循环

**核心思想**：Think → Act → Observe → 循环

**架构图**：
```
┌─────────────────────────────────────────────────────────────┐
│                    ReAct 架构                                │
├─────────────────────────────────────────────────────────────┤
│  ┌─────────────┐                                            │
│  │  用户输入    │                                            │
│  └──────┬──────┘                                            │
│         ▼                                                   │
│  ┌─────────────┐    ┌─────────────┐    ┌─────────────┐      │
│  │   Think     │───▶│    Act      │───▶│  Observe    │      │
│  │  (思考)     │    │  (行动)     │    │  (观察)     │      │
│  └──────┬──────┘    └─────────────┘    └──────┬──────┘      │
│         │                                     │             │
│         └─────────────────────────────────────┘             │
│                      循环直到完成                            │
└─────────────────────────────────────────────────────────────┘
```

**代码实现**：
```python
from langchain.agents import create_react_agent
from langchain_openai import ChatOpenAI
from langchain_core.tools import tool

@tool
def search(query: str) -> str:
    """搜索文档"""
    return f"搜索结果: {query}"

@tool
def calculate(expression: str) -> str:
    """数学计算"""
    return str(eval(expression))

llm = ChatOpenAI(model="gpt-4")
tools = [search, calculate]

# 创建ReAct Agent
agent = create_react_agent(llm, tools, prompt)

# 执行
result = agent.invoke({"input": "搜索AI架构并计算2+2"})
```

**适用场景**：
- 单步或少步骤任务
- 需要动态决策的场景
- 工具调用简单的场景

**优缺点**：
| 优点 | 缺点 |
|------|------|
| 实现简单 | 缺乏全局规划 |
| 响应快速 | 容易陷入局部最优 |
| 易于调试 | 不适合复杂任务 |

### 2.2 PlanExec：计划-执行分离

**核心思想**：Plan → Execute → Replan → 循环

**架构图**：
```
┌─────────────────────────────────────────────────────────────┐
│                    PlanExec 架构                             │
├─────────────────────────────────────────────────────────────┤
│  ┌─────────────┐                                            │
│  │  用户输入    │                                            │
│  └──────┬──────┘                                            │
│         ▼                                                   │
│  ┌─────────────┐                                            │
│  │    Plan     │  生成完整计划                                │
│  │  (计划)     │  [步骤1, 步骤2, 步骤3...]                   │
│  └──────┬──────┘                                            │
│         ▼                                                   │
│  ┌─────────────┐    ┌─────────────┐    ┌─────────────┐      │
│  │ Execute-1   │───▶│ Execute-2   │───▶│ Execute-3   │      │
│  │  (执行)     │    │  (执行)     │    │  (执行)     │      │
│  └──────┬──────┘    └──────┬──────┘    └──────┬──────┘      │
│         │                  │                  │             │
│         └──────────────────┼──────────────────┘             │
│                            ▼                                │
│                     ┌─────────────┐                         │
│                     │   Replan    │  根据结果调整计划         │
│                     │  (重规划)   │                         │
│                     └─────────────┘                         │
└─────────────────────────────────────────────────────────────┘
```

**代码实现**：
```python
from langgraph.prebuilt import create_react_agent
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(model="gpt-4")

# PlanExec Agent
class PlanExecAgent:
    def __init__(self, llm, tools):
        self.llm = llm
        self.tools = tools
    
    def plan(self, task: str) -> list:
        """生成执行计划"""
        prompt = f"""
        为以下任务生成详细的执行计划：
        任务：{task}
        
        请返回JSON格式的计划：
        [{{"step": 1, "action": "...", "tool": "..."}}, ...]
        """
        response = self.llm.invoke(prompt)
        return parse_plan(response.content)
    
    def execute(self, plan: list) -> dict:
        """执行计划"""
        results = []
        for step in plan:
            tool = self.get_tool(step["tool"])
            result = tool.invoke(step["action"])
            results.append({"step": step["step"], "result": result})
        return {"results": results}
    
    def run(self, task: str):
        """完整执行流程"""
        plan = self.plan(task)
        results = self.execute(plan)
        return results
```

**适用场景**：
- 复杂多步骤任务
- 需要全局规划的场景
- 任务可分解为独立子任务

**优缺点**：
| 优点 | 缺点 |
|------|------|
| 全局规划能力强 | 计划可能过时 |
| 任务分解清晰 | 灵活性较差 |
| 易于并行执行 | 重规划开销大 |

### 2.3 Reflect：自我反思优化

**核心思想**：Act → Reflect → Improve → 循环

**架构图**：
```
┌─────────────────────────────────────────────────────────────┐
│                    Reflect 架构                              │
├─────────────────────────────────────────────────────────────┤
│  ┌─────────────┐                                            │
│  │  用户输入    │                                            │
│  └──────┬──────┘                                            │
│         ▼                                                   │
│  ┌─────────────┐    ┌─────────────┐    ┌─────────────┐      │
│  │    Act      │───▶│  Reflect    │───▶│   Improve   │      │
│  │  (行动)     │    │  (反思)     │    │  (改进)     │      │
│  └──────┬──────┘    └─────────────┘    └──────┬──────┘      │
│         │                                     │             │
│         └─────────────────────────────────────┘             │
│                   直到质量达标                               │
└─────────────────────────────────────────────────────────────┘
```

**代码实现**：
```python
class ReflectAgent:
    def __init__(self, llm, max_iterations=3):
        self.llm = llm
        self.max_iterations = max_iterations
    
    def act(self, task: str) -> str:
        """执行任务"""
        prompt = f"执行以下任务：{task}"
        return self.llm.invoke(prompt).content
    
    def reflect(self, task: str, result: str) -> str:
        """反思结果"""
        prompt = f"""
        任务：{task}
        当前结果：{result}
        
        请分析结果的质量，指出不足之处，并给出改进建议。
        """
        return self.llm.invoke(prompt).content
    
    def improve(self, task: str, result: str, reflection: str) -> str:
        """根据反思改进结果"""
        prompt = f"""
        任务：{task}
        当前结果：{result}
        反思：{reflection}
        
        请根据反思改进结果。
        """
        return self.llm.invoke(prompt).content
    
    def run(self, task: str) -> str:
        """完整执行流程"""
        result = self.act(task)
        
        for i in range(self.max_iterations):
            reflection = self.reflect(task, result)
            if "质量良好" in reflection:
                break
            result = self.improve(task, result, reflection)
        
        return result
```

**适用场景**：
- 质量要求高的任务
- 需要迭代优化的场景
- 创意生成类任务

**优缺点**：
| 优点 | 缺点 |
|------|------|
| 输出质量高 | 迭代开销大 |
| 自我优化能力强 | 收敛速度慢 |
| 适合创意任务 | 不适合实时响应 |

### 2.4 混合范式：多范式融合

**核心思想**：根据任务动态选择最佳范式

**架构图**：
```
┌─────────────────────────────────────────────────────────────┐
│                    混合范式架构                               │
├─────────────────────────────────────────────────────────────┤
│  ┌─────────────┐                                            │
│  │  用户输入    │                                            │
│  └──────┬──────┘                                            │
│         ▼                                                   │
│  ┌─────────────┐                                            │
│  │  范式路由器  │  根据任务类型选择范式                        │
│  └──────┬──────┘                                            │
│         │                                                   │
│    ┌────┴────┬────────────┬────────────┐                    │
│    ▼         ▼            ▼            ▼                    │
│  ┌─────┐  ┌─────┐  ┌─────────┐  ┌─────────┐                │
│  │ReAct│  │Plan │  │ Reflect │  │ 混合    │                │
│  └─────┘  └─────┘  └─────────┘  └─────────┘                │
└─────────────────────────────────────────────────────────────┘
```

**代码实现**：
```python
class HybridAgent:
    def __init__(self, llm):
        self.llm = llm
        self.agents = {
            "react": ReactAgent(llm),
            "plan_exec": PlanExecAgent(llm),
            "reflect": ReflectAgent(llm),
        }
    
    def route(self, task: str) -> str:
        """根据任务类型选择范式"""
        prompt = f"""
        分析以下任务类型，选择最合适的Agent范式：
        任务：{task}
        
        选项：
        1. react - 单步或少步骤任务
        2. plan_exec - 复杂多步骤任务
        3. reflect - 质量要求高的任务
        
        请返回范式名称。
        """
        response = self.llm.invoke(prompt)
        return response.content.strip()
    
    def run(self, task: str) -> str:
        """完整执行流程"""
        paradigm = self.route(task)
        agent = self.agents[paradigm]
        return agent.run(task)
```

**适用场景**：
- 复杂多变的任务
- 需要灵活选择策略的场景
- 企业级生产环境

### 2.5 Harness：工程架构范式

**核心思想**：用工程手段约束模型不确定性

```
│  │  ┌─────────┐ ┌─────────┐ ┌─────────┐ ┌─────────┐   │    │
│  │  │ Logging │ │ Auth    │ │ Rate    │ │ Retry   │   │    │
│  │  │ 中间件  │ │ 中间件  │ │ Limit   │ │ 中间件  │   │    │
│  │  └─────────┘ └─────────┘ └─────────┘ └─────────┘   │    │
│  └─────────────────────────────────────────────────────┘    │
│                          │                                  │
│                          ▼                                  │
│  ┌─────────────────────────────────────────────────────┐    │
│  │                 Sandbox 沙箱层                       │    │
│  │  ┌─────────┐ ┌─────────┐ ┌─────────┐ ┌─────────┐   │    │
│  │  │ 代码    │ │ 网络    │ │ 文件    │ │ 资源    │   │    │
│  │  │ 隔离    │ │ 隔离    │ │ 隔离    │ │ 限制    │   │    │
│  │  └─────────┘ └─────────┘ └─────────┘ └─────────┘   │    │
│  └─────────────────────────────────────────────────────┘    │
│                          │                                  │
│                          ▼                                  │
│  ┌─────────────────────────────────────────────────────┐    │
│  │                 Memory 记忆层                        │    │
│  │  ┌─────────┐ ┌─────────┐ ┌─────────┐               │    │
│  │  │ 上下文  │ │ 历史    │ │ 事实    │               │    │
│  │  │ 记忆    │ │ 记忆    │ │ 记忆    │               │    │
│  │  └─────────┘ └─────────┘ └─────────┘               │    │
│  └─────────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────────┘
```

**核心特性**：
1. **Middleware层**：日志、认证、限流、重试等横切关注点
2. **Sandbox层**：代码、网络、文件、资源隔离
3. **Memory层**：上下文、历史、事实三层记忆
4. **断点续跑**：任务中断后可恢复执行

## 四、选型指南

### 4.1 决策矩阵

| 任务特征 | 推荐范式 | 原因 |
|---------|---------|------|
| 单步 + 简单工具 | ReAct | 实现简单，响应快 |
| 多步骤 + 可分解 | PlanExec | 全局规划能力强 |
| 高质量 + 可迭代 | Reflect | 自我优化能力强 |
| 复杂多变 | 混合范式 | 灵活选择策略 |
| 生产环境 + 高可用 | Harness | 工程约束保障 |

### 4.2 组合使用策略

在实际生产中，推荐"Harness + 混合范式"的组合策略：

```python
# 组合使用
class ProductionAgent:
    def __init__(self):
        # Harness层：工程约束
        self.middleware = MiddlewareStack([
            LoggingMiddleware(),
            AuthMiddleware(),
            RateLimitMiddleware(),
            RetryMiddleware(),
        ])
        
        # 混合范式层：灵活选择
        self.hybrid_agent = HybridAgent(llm)
    
    def run(self, task: str) -> str:
        """生产环境执行"""
        # 应用Harness约束
        with self.middleware:
            # 使用混合范式
            return self.hybrid_agent.run(task)
```

## 五、面试高频问题

### Q1：ReAct和PlanExec的核心区别是什么？

**A**：ReAct是动态决策，每一步都重新思考；PlanExec是静态计划，先生成完整计划再执行。ReAct适合简单任务，PlanExec适合复杂任务。

### Q2：Harness为什么是工程架构范式？

**A**：Harness定义的是"如何用工程手段约束模型不确定性"，而不是"怎么做决策"。它通过Middleware、Sandbox、Memory等工程手段，保障Agent在生产环境的稳定性。

### Q3：什么时候用混合范式？

**A**：任务复杂多变、需要灵活选择策略时用混合范式。它可以根据任务类型动态选择ReAct、PlanExec或Reflect，兼顾灵活性和性能。

理解5大Agent范式是架构师的必备内功。在实际生产中，推荐"Harness + 混合范式"的组合策略，兼顾工程约束和灵活选择。
