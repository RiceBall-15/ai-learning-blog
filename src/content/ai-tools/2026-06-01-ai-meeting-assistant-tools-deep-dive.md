### 3.3 集成配置实战

**Otter.ai + Slack 集成示例**：

```python
# 通过Otter API实现自动摘要推送
import requests
from slack_sdk import WebClient

OTTER_API_KEY = "your-api-key"
SLACK_BOT_TOKEN = "xoxb-your-token"
SLACK_CHANNEL = "#meeting-notes"

def on_meeting_end(meeting_id):
    """会议结束后自动处理"""
    
    # 1. 获取会议转录
    transcript = requests.get(
        f"https://api.otter.ai/v1/streams/{meeting_id}",
        headers={"Authorization": f"Bearer {OTTER_API_KEY}"}
    ).json()
    
    # 2. 生成结构化摘要
    summary = generate_structured_summary(transcript)
    
    # 3. 提取Action Items
    action_items = extract_action_items(transcript)
    
    # 4. 推送到Slack
    slack = WebClient(token=SLACK_BOT_TOKEN)
    slack.chat_postMessage(
        channel=SLACK_CHANNEL,
        blocks=[
            {
                "type": "header",
                "text": {"type": "plain_text", "text": f"📋 会议摘要: {summary['title']}"}
            },
            {
                "type": "section",
                "text": {"type": "mrkdwn", "text": summary['content']}
            },
            {
                "type": "section",
                "text": {"type": "mrkdwn", "text": format_action_items(action_items)}
            }
        ]
    )
    
    # 5. 同步到Notion
    sync_to_notion(summary, action_items)

def generate_structured_summary(transcript):
    """使用LLM生成结构化摘要"""
    prompt = f"""
    请将以下会议转录整理为结构化摘要，包含：
    1. 核心议题（3-5个）
    2. 关键决策
    3. 行动项（负责人、截止日期）
    4. 开放问题
    
    转录内容：
    {transcript['text']}
    """
    
    # 调用LLM API生成摘要
    response = call_llm_api(prompt)
    return parse_structured_summary(response)
```

## 四、进阶技巧：最大化AI会议助手价值

### 4.1 会前准备清单

```

□ 检查网络连接稳定性

```

### 4.2 会议中的最佳实践

1. **发言清晰**：避免多人同时发言，降低转录错误率
2. **使用议题标记**：如"接下来讨论X议题"，帮助AI更好地分割话题
3. **明确决策**：重要决策时明确说"我们决定..."，确保AI捕获
4. **指定负责人**：Action Item明确说"由@张三负责..."

### 4.3 会后处理流程


## 五、ROI计算：AI会议助手值不值？

### 5.1 成本收益分析

假设一个10人团队，每周平均5次会议，每次会议平均1小时：

```
传统方式成本：
├─ 手动记录：30分钟/会议 × 5 = 2.5小时/周
├─ 整理纪要：20分钟/会议 × 5 = 1.7小时/周
├─ 跟进Action：15分钟/会议 × 5 = 1.2小时/周
└─ 总计：5.4小时/周 × 52周 = 281小时/年

假设团队成员平均时薪：¥200/小时
传统方式年成本：281 × 200 = ¥56,200

AI会议助手成本：
├─ 工具订阅：¥99/月 × 12 = ¥1,188/年
├─ 审核整理：5分钟/会议 × 5 = 0.4小时/周
└─ 总计：20.8小时/年 + ¥1,188

AI方式年成本：20.8 × 200 + ¥1,188 = ¥5,348

年节省：¥56,200 - ¥5,348 = ¥50,852
投资回报率：4,176%
```
