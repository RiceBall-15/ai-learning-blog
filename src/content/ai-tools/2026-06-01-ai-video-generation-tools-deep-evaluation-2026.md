### 2.1 核心能力

Sora是目前技术实力最强的AI视频生成工具，其核心优势在于：

- **极致画质**: 1080p输出，光影、纹理、物理效果业界顶级

### 3.3 运动控制实战

```python
# Kling的运动笔刷功能是其核心差异化能力

"""
运动控制模板示例:

场景: 汽车在山路上行驶
- 运动主体: 汽车（标记为蓝色区域）
- 运动轨迹: 从左下角到右上角的S型路线
- 运动速度: 中速
- 镜头跟随: 汽车始终在画面中央偏左位置

使用方法:
1. 上传参考图（汽车正面照）
2. 在运动画布上标记汽车区域
3. 绘制运动轨迹线
4. 设置速度和镜头参数
"""

# Kling API调用示例（概念代码）
def generate_with_motion_control():
    """使用运动控制生成视频"""
    params = {
        "model": "kling-2.0",
        "prompt": "一辆红色跑车在蜿蜒的山路上高速行驶，背景是壮丽的日落山脉",
        "image": "car_reference.png",  # 参考图
        "negative_prompt": "模糊, 变形, 抖动",
        "cfg_scale": 0.7,
        "motion_brush": {
            "regions": [
                {
                    "area": "car",  # 标记汽车区域
                    "trajectory": [[0.2, 0.8], [0.5, 0.5], [0.8, 0.2]],  # S型轨迹
                    "speed": "medium"
                }
            ],
            "camera": {
                "type": "follow",  # 跟随镜头
                "subject": "car"
            }
        },
        "duration": 10,  # 10秒
        "resolution": "1080p"
    }
    return kling_api.generate(params)
```

### 9.2 多工具编排架构

```python
from dataclasses import dataclass
from enum import Enum

class VideoTaskType(Enum):
    STORYBOARD = "storyboard"       # 分镜预览
    FINAL_RENDER = "final_render"   # 最终渲染
    BATCH素材 = "batch"             # 批量素材
    RAPID_PROTOTYPE = "prototype"   # 快速原型

@dataclass
class VideoTask:
    task_type: VideoTaskType
    prompt: str
    duration: int       # 秒
    resolution: str     # 1080p, 720p
    budget: float       # 预算限制

class MultiToolOrchestrator:
    """多工具编排器：根据任务类型选择最优工具"""
    
    TOOL_ROUTING = {
        # 快速原型 → Hailuo (速度优先)
        VideoTaskType.RAPID_PROTOTYPE: ["hailuo", "pika"],
        
        # 分镜预览 → Kling (性价比+控制力)
        VideoTaskType.STORYBOARD: ["kling", "runway"],
        
        # 最终渲染 → Sora (画质优先)
        VideoTaskType.FINAL_RENDER: ["sora", "kling"],
        
        # 批量素材 → Hailuo + Kling (速度+性价比)
        VideoTaskType.BATCH素材: ["hailuo", "kling"],
    }
    
    def route(self, task: VideoTask) -> str:
        """根据任务类型和预算选择工具"""
        candidates = self.TOOL_ROUTING[task.task_type]
        
        # 按预算过滤
        for tool in candidates:
            if self._check_budget(tool, task):
                return tool
        
        # 降级到最便宜的工具
        return candidates[-1]
    
    def _check_budget(self, tool: str, task: VideoTask) -> bool:
        """检查工具是否在预算内"""
        COST_PER_SECOND = {
            "sora": 0.12,    # $/秒
            "kling": 0.15,   # ¥/秒
            "runway": 0.10,  # $/秒
            "pika": 0.08,    # $/秒
            "hailuo": 0.05,  # ¥/秒
            "vidu": 0.12,    # ¥/秒
        }
        estimated_cost = COST_PER_SECOND.get(tool, 999) * task.duration
        return estimated_cost <= task.budget
```
